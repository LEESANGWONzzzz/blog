# 원본 가이드 검수 결과

대상: 「네이버 블로그 자동화 툴 — 정리 가이드」의 5-1 프롬프트(v1, 기준일 2026-09-05)와 설치 절차.
수정판: `docs/writing-rules.md` (v1.1).

## A. 프롬프트 오류 — 수정함

| # | 원본 | 문제 | 수정 |
|---|---|---|---|
| 1 | 1절 "목표는 두 가지다." | 목표가 하나도 적혀 있지 않음 | 목표 1은 원본 4-6에 "1순위 목표"로 적힌 AI 브리핑 인용으로 채움. 목표 2는 근거가 없어 프로필 항목으로 넘기고, 비어 있으면 질문하게 함 |
| 2 | 2절 "4절 '사실 자산'에 없는…" | 4절은 "글쓰기 공식"이고, "사실 자산" 절은 어디에도 없음 → 이 규칙을 적용할 수 없음 | 3절 "사실 자산"을 새로 만듦 (프로필 · 이번 입력 · 사진에서 보이는 것) |
| 3 | 2절 "7절 규칙을 따른다" | 7절이 없음. 수치 규칙은 5절 | 절 번호를 다시 매기고 참조를 6절(수치 무결성)로 고침 |
| 4 | 1절 "아래 10절의 초안 JSON" | 10절이 없음. 출력 형식은 6절 | 7절로 고침 |
| 5 | 4-3 "6-4에서 골라" | 6-4가 없음. 권위 문구 뱅크는 4-4 | 5-4로 고침 |
| 6 | 1절 "초안 JSON + 검수 보고 두 개" | 검수 보고 형식이 정의돼 있지 않음 | 7-2에 검수 보고 형식 추가 (수치 출처표 · 모자이크 · 사실 대조 포함) |
| 7 | 3절 `## **3. 화자` … 끝의 `**` | 굵게 표시 문법이 깨져서 3절 전체가 굵게 나오거나 그대로 노출됨 | 문법 정리 |
| 8 | 프롬프트 전체가 ```` ``` ```` 블록 안에 있고, 안에 또 ```` ``` ```` 블록이 있음 | 안쪽 블록에서 바깥 블록이 끝나서 붙여넣을 때 잘림 | 규칙을 독립 파일로 분리. 붙여넣을 때는 파일을 통째로 씀 |
| 9 | 부록 "초안은 그냥 바로 저장한다" ↔ 2절 "마커가 있으면 저장 가능 판정을 내리지 않는다" | 서로 충돌. 마커가 남은 초안이 저장될 수 있음 | 절대 규칙을 우선함: 형식 오류나 마커가 **없을 때만** 사람 승인 없이 바로 임시저장. `lint_draft.js`가 강제함 |
| 10 | 4-4 권위 문구 "2022년에 레버리지 ETF로 800만원", 3절 "1,380원에 물려봤어요" | 원본 작성자의 개인 경험담이 예시로 들어 있음. 다른 사람이 쓰면 AI가 그대로 옮겨 **사실을 지어내는 결과**가 됨 (절대 규칙 1 위반) | 권위 문구를 `{연도}{상품}{금액}` 틀로 바꾸고, 프로필의 "경험담"으로만 채우게 함. 리듬 예시에는 "내용은 쓰지 않는다"를 명시 |
| 11 | 3절 표 "형식(블로그명)" | 블로그명 자리표시자가 채워지지 않음 | "형식"으로 바꾸고, 블로그명은 프로필로 이동 |
| 12 | JSON의 `video` 필드 | 규칙이 없음 | 현재 버전 미지원 → `null` 고정 |
| 13 | 투자 면책 "마지막 블록" | 면책 문구 내용이 없어 AI가 지어내게 됨 | 프로필의 "면책 문구"를 쓰고, 비어 있으면 질문 |
| 14 | 태그 5~10개 | 네이버는 태그를 발행 설정 화면에서 받는데, 발행 화면은 가드로 막혀 있음 → 자동 입력과 발행 차단이 충돌 | 태그는 `publish_checklist.txt`로 넘기고 사람이 발행할 때 입력 |
| 15 | 4-6 "네이버 메이트" | 같은 문서 다른 곳에서는 "AI 브리핑"이라고 부름 | "AI 브리핑"으로 통일 (실제 서비스명은 아래 C 참고) |
| 16 | 분량 1,800~2,200자 | 공백 포함인지 제외인지 없음 | 공백 포함으로 정함. 검사기는 두 값을 모두 출력 |

## B. 설치 절차 — Mac 기준으로 바뀐 점

| 원본 (Windows) | 공식 문서 확인 결과 (2026-10-02) | 반영 |
|---|---|---|
| "클로드 코드를 실행하려면 먼저 Node.js가 필요" | 공식 권장 설치는 `curl -fsSL https://claude.ai/install.sh \| bash` (네이티브)로, Node.js가 필요 없음. npm 방식도 가능 | Node.js는 이 도구의 Playwright 스크립트용으로만 설치 |
| "Claude Pro 이상 권장, 무료 플랜은 제한" | 공식 문서: Pro·Max·Team·Enterprise·Console 계정이 **필요**하고, 무료 플랜에는 Claude Code가 포함되지 않음 | "권장" → "필수"로 고침 |
| PowerShell `Set-ExecutionPolicy` 오류 | Mac에는 해당 없음 | 삭제 |
| `C:\Users\…` 경로, `!` 명령 경로 문제 | Mac은 `~/Desktop/…`. 스크립트가 프로젝트 루트 기준으로 경로를 풀기 때문에 실행 위치와 무관 | `config.js`의 `resolveFromRoot` |
| 플랜 모드로 프롬프트를 넣어 처음부터 생성 | 이 저장소에 결과물이 이미 있음 | 바로 `/write` 사용 |

## C. 확인하지 못한 것 (추가 확인 필요)

- **네이버 에디터 셀렉터 전체** (`scripts/lib/selectors.js`): 실제 로그인 화면에서 확인하지 않은 초기값입니다. 첫 실행 때 실측이 필요합니다.
- **발행 버튼 `data-testid="seOnePublishBtn"`**: 원본 가이드 값을 그대로 썼습니다. 맞는지 확인하지 못해서, 버튼 글자에 "발행"이 들어가면 모두 막도록 이중으로 처리했습니다.
- **"AI 브리핑" / "네이버 메이트"의 정확한 현재 서비스명과 인용 방식**: 확인 불가.
- **목표 2, 화자 경험담, 면책 문구**: 사용자만 알 수 있는 정보라 프로필에 빈칸으로 남겼습니다.
