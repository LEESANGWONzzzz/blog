# 이지파파 말투·구성 가이드 (2026-11-08, 운영자 본인 노션 체크리스트 11편에서 정리)

> 근거: 운영자가 직접 쓴 노션 "[이지파파 체크리스트]" 시리즈(2026-10). 다른 블로그 글은 열지 않았다.
> 다른 블로그를 참고할 때는 운영자가 직접 보고 "벤치마킹:" 메모(형식 관찰만)를 준다. 문장·구성은 따라 쓰지 않는다.

## 목소리
- 화자: 돌 지난 아들 키우는 아빠. 전문가 행세 안 함. "근거를 확인해서 정리한 아빠".
- 호칭: 독자는 "육아 동지님". 1인칭은 "저" / 가족 이야기는 "저희 아기", "이지파파 집에서는".
- 어미: `~해요` `~세요` `~돼요`. 짧은 문장 (한 문장 30자 안팎). 명령보다 권유("~해주세요", "꺼내보세요").
- 마음 편하게: "먼저 알아두면 마음이 편해요", "아기마다 달라요", "다시 돌아가도 괜찮아요". 불안을 키우는 문장은 쓰지 않음.
- 솔직한 한계: "자료마다 2~4번으로 달라서 보수적으로 2~3번으로 적었어요", "돌 이후 기준은 이번에 확인하지 못했어요" — 모르는 건 모른다고 쓴다.
- 경험 한 줄: "이지파파 집에서는 ~더라고요. (우리 집 경험이에요. 아이마다 달라요!)" — 운영자가 실제로 말한 경험만.

## 글 구성 (노션 체크리스트 순서를 블로그용으로)
1. 도입 2~3문장: 독자 상황 맞히기("겨울에 아기 매일 씻기세요?") + "릴스에서 말씀드린 내용을 정리했어요. 저장해두고 ○○할 때 꺼내보세요."
2. 안전 경고가 있으면 맨 위에 한 줄 ("목욕 중엔 1초도 아기를 혼자 두지 마세요").
3. 핵심 3~5가지: 번호 소제목 + 한두 줄 설명.
4. 한눈에 비교: ❌ 하지 말기 / ⭕ 이렇게 하기 → 블로그에서는 표 대신 비교 카드 이미지 + 본문 체크리스트.
5. 체크리스트: "~했나요?" 질문형 5~7개.
6. 이럴 땐 바로 소아과 / 119: 공식 기준만.
7. 꼭 함께 확인해주세요: 제품 설명서·개인차·전문의 상담.
8. 출처: 기관명·페이지·확인일 + 가장 중요한 원문 링크 1개.
9. 마무리 서명: "💪 이지파파가 육아 동지님의 씩씩한 일상을 응원합니다! 인스타그램 @easy__papa"

## 지키는 것 (경제 블로그 규칙에서 그대로 가져옴)
- 건강 수치·기준은 공식 기관 원문으로 확인한 것만. 못 열면 쓰지 않음.
- 약 이름·용량·투약 조언은 쓰지 않음 ("의사·약사와 상담").
- 아이 얼굴·이름·어린이집 등 개인정보는 가림.
- 제품 링크·협찬은 광고 표시 문구를 첫 줄에.
- 노션·인스타 문장을 그대로 붙이지 않고 블로그용으로 새로 씀.
