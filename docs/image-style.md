# 이미지 스타일 기준 (레퍼런스 학습 정리)

> 2026-10-08 운영자가 준 레퍼런스 4장을 보고 정리했다. 이미지는 **구성과 분위기만** 배우고, 그대로 베끼지 않는다.
> 정보 카드는 `scripts/make_cards.js`, AI 일러스트는 `scripts/generate_image.js`가 만든다.

## 레퍼런스에서 가져온 것

| 레퍼런스 | 가져올 것 | 가져오지 않을 것 |
|---|---|---|
| ① 배당금 계산 카드 (남색 제목 띠 + 항목/값 표 + `A × B = 결과` 빨간 강조) | 남색 제목 띠, 2열 항목·값 표, 계산식 한 줄, 결과만 빨간색 → `table` 카드 + `navy` 테마 | 실제 기업 로고·사명·건물 사진, 확인 안 된 숫자, 하단이 잘린 레이아웃 |
| ② 증권사 리포트 차트 (선·막대 + "자료: 기관") | 하나의 지표만 그린 단순 그래프, 마지막 값 강조, 아래에 출처 → `chart` 카드 | 증권사 차트 이미지 자체 (저작권), 축이 두 개인 복잡한 그래프 |
| ③④ 수채 애니메이션풍 감성 그림 (손글씨 제목 + 따뜻한 햇살 + 일상 장면) | 표지·도입부의 감정 이입용 그림 → AI 일러스트 `style: "watercolor"` | 실존 인물, 학교·기업 로고, 그림 속 긴 문장 |

## 카드 종류 고르기 (`cards.json`의 `kind`)

| 글에서 하는 일 | kind | 예 |
|---|---|---|
| 글 첫 이미지 | `cover` 또는 watercolor 일러스트 | 제목 + 핵심 한 줄 |
| 숫자 계산을 보여줄 때 | `table` (+ `formula`) | 원금·금리·이자 → `360만 원 × 3.0% = …` |
| A안 vs B안 | `compare` | 적금 vs 예금, 전세 vs 월세 |
| 추이·변화 | `chart` (`bar`/`line`, 2~8개 값) | 기준금리 연도별, 물가상승률 월별 |
| 핵심 숫자 하나 | `number` | 월 최대 50만 원 |
| 조건·정리 | `list` | 신청 자격 체크 |
| 신청 순서 | `steps` | 1 → 2 → 3 |

- 한 글 안에서 **같은 kind를 연속으로 쓰지 않는다.** 권장 구성(5~6장): `cover`(또는 watercolor) → `table`/`number` → `compare` 또는 `chart` → `steps` → `list`(마무리 체크리스트).
- 테마: 숫자·표·그래프는 `navy`, 정리·순서는 `classic`. 한 글에서 두 테마를 섞어도 된다.
- `bg`: 직접 찍은 사진(`input/photos/_mosaic/`)이나 공공누리 자료(`input/images/official/`)를 흐리게 깔 수 있다. 다른 사진은 쓰지 않는다.

## 숫자 규칙 (그대로 유지)
- 카드의 모든 숫자(표 값, 계산식, 그래프 값과 라벨)는 **본문에 같은 형태로** 있어야 한다. `--draft` 검사가 막는다.
- 계산식 결과는 직접 계산해 본문에도 같은 숫자로 적는다. 레퍼런스 ①처럼 "배당수익률 19.11%" 같은 값은 상식과 크게 다르면 출처를 다시 확인한다.
- 그래프 카드는 `note`에 `출처: 기관명 · 기준일`이 없으면 만들지 않는다. 그래프 값은 공식 통계(한국은행 ECOS, 통계청 KOSIS 등)에서만 가져온다.
- 소수점을 그대로 보이려면 값을 문자열로 쓴다 (`"3.0"` → 3.0%).

## AI 일러스트 (watercolor)
- API 키가 없으면 `generate_image.js`가 `image_prompts.md`를 만든다 → 운영자가 ChatGPT에 붙여넣어 그림을 만들고, 적힌 파일 이름으로 `input/images/generated/`에 저장한다.
- 그림 속 글자는 짧은 제목 한 줄까지만. 숫자는 그림에 넣지 않는다 (숫자는 카드로).
- 등장인물은 실존하지 않는 사람. 출퇴근길·사무실·집·시장처럼 직장인 일상 장면.
- AI 이미지를 쓰면 면책 문구 앞에 "이 글의 일러스트는 AI로 만든 이미지예요." 한 줄을 넣는다.
