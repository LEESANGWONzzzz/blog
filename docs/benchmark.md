## 1. 제목 패턴

- **키워드를 맨 앞에 둔다.** 정보글 4편은 메인 키워드(상품명·정책명·대상)로 시작한다. 회고 1편만 목표 금액으로 시작한다. 한정어로 연도나 대상(30대 직장인 등)을 붙인다.
- 형태는 세 가지다.
  - `키워드 + 질문형 ~는? / ~까?` (3편): 검색 질문을 그대로 제목으로 쓴다.
  - `키워드 + 사실 확정! + 하위 주제 나열` (1편): 뉴스형이다. 뒤에 서브 키워드를 공백으로 이어 붙인다.
  - `목표 금액 + 화자 정체성 + 직접 해본 + 기간 결산` (1편): 경험형이다.
- 질문형 제목 끝에 `조회 방법`처럼 서브 키워드를 덧붙이기도 한다.
- 길이는 21~43자로 들쭉날쭉하다. `!`·`?` 같은 특수문자를 쓴다.
  → 우리 규칙(25~32자, 특수문자 없음)과 다르다. 형태만 참고한다.
- RSS 태그는 메인 키워드의 변형 3~5개다 (키워드 / 키워드+대상 / 키워드+조회 등).

## 2. 글 골격 (5편이 거의 같은 템플릿)

모든 글이 같은 상단·하단 틀을 쓴다. 에디터 컴포넌트 ID까지 같은 걸 보면 저장해 둔 템플릿을 불러 쓰는 것으로 보인다.

```
[대표 이미지 1장 — PNG, 제목 카드로 추정]
[인용구(기본형) — 제목을 한 번 더 씀]
(도입 1~2문단 — 글마다 있기도 하고 없기도 함)
[표 — "목차" + 번호 붙은 소제목 3~4개]
── 반복 ──
[인용구(밑줄형) — 소제목]
[사진 0~1장]
[텍스트 1블록 — 여러 줄]
──────────
[인용구(밑줄형) — "블로그명's 출근길 3분 요약" 같은 고정 마무리 소제목]
[텍스트 1블록 — 결론 요약 + 화자 결정 / 권유]
[링크 카드 2개 — 본인 대표 글 고정 2편 (내부 링크)]
[마지막 이미지 1장 — PNG, 서명·배너로 추정]
```

- 소제목 수: 목차 기준 3~4개, 마지막은 거의 항상 고정 "요약" 섹션이다.
- 마지막 고정 요약 섹션의 이름에 블로그 콘셉트("출근길 3분")가 들어간다. 브랜드를 반복해서 각인시키는 장치다.
- 내부 링크 카드 2개는 5편 모두 같은 글이다. 자산 형성 경험담 1편과 연금계좌 후기 1편으로, 화자 신뢰를 쌓는 "대표작" 역할을 한다.

## 3. 도입부

- **바로 결론형** (정보글 3편): 도입 문단 없이 목차로 들어가거나, 첫 소제목 바로 뒤 첫 문장에 핵심 숫자를 단정해서 쓴다. 공감 문장이 없다.
- **예고형** (정책 해설 1편): 도입 1문단에서 "이 글에 무엇이 들어있는지"를 나열하고, 대상 독자를 지정해서 끝까지 읽기를 권한다.
- **사건 계기형** (본인 데이터 1편): 짧은 2문장으로 시작한다. "어떤 알림을 받았다 → 그래서 조회해봤다"는 흐름이다.
- **결산형** (회고 1편): 이번 달 평가를 한 줄로 던지고, 지난달 목표를 점검하겠다고 예고한다.
- 권위 문구(우리 5-4)에 해당하는 줄은 따로 없다. 대신 **본인 실제 데이터**(가입일·보험료·팔로워 수 등)를 본문에 그대로 공개해서 신뢰를 만든다.

## 4. 소제목

- 모두 **인용구(밑줄형)** 컴포넌트로 들어간다. 본문 강조용 인용구는 없다.
- 형태는 세 가지가 섞여 있다.
  - 질문형: `{대상}, 어디인가요?` / `앞으로 어떤 단계를 밟나요?` / `그래서 {결과}는 언제쯤일까요?`
  - **숫자 결론형**: 소제목 자체에 답 숫자를 넣는다. 예: `기본 한도: {대상A} {금액}, {대상B} {금액}` / `{조건}이면 할증 {n}%` / `월 보험료 {금액}`
  - 명사형: `수요예측 결과`, `어떤 회사인지`, `리스크 두 가지`
- **숫자 결론형 소제목**은 목차 표에도 그대로 나온다. 그래서 목차만 읽어도 답이 보인다.
- 소제목 바로 뒤 첫 문장은 주어와 숫자를 갖춘 완결 문장이다. 지시어로 시작하지 않는다. 우리 5-6(AI 브리핑 인용 단위)과 같은 방향이다.

## 5. 문단·텍스트 블록

- 한 텍스트 블록에 2~9줄을 몰아 넣는다. 블록 하나가 150~500자다.
- 사진이 없는 연속 텍스트는 가장 길 때 약 220~510자다. 정책 해설 글 1편만 500자를 넘었다.
- 단계·조건은 `첫째/둘째/셋째` 또는 `1. 2. 3.` 번호 줄로 나열한다. `•` 글머리표로 연표를 쓰기도 한다.
- 굵게·글자 크기 같은 강조 서식이 블록마다 4~25군데 들어간다. 숫자와 결론 문장에 집중된다.
- 어미 혼합: 사실·수치는 `~입니다`, 본인 이야기는 `~요 / ~더라구요`. 우리 4절 규칙과 같은 구조다.
- 면책: 세금 글 1편만 요약 블록 끝에 `※ 정보 제공 목적 + 공식 채널 확인` 형태의 한 줄 면책을 붙였다.

## 6. 사진 배치

| # | 이미지 수 | 대표·서명 제외 | 캡션 |
|---|---|---|---|
| 1 | 10 | 8 | 0 |
| 2 | 8 | 6 | 0 |
| 3 | 5 | 3 | 0 |
| 4 | 6 | 4 | 0 |
| 5 | 5 | 3 | 0 |

- 본문 사진은 **소제목마다 0~1장**, 소제목 바로 아래에 둔다. 사진 → 설명 텍스트 순서다.
- 파일명이 휴대폰 캡처 형식(`IMG_xxxx`)이고 번호가 연속이다. 앱·공시·기사 화면을 캡처해서 쓰는 것으로 추정된다.
  이미지 파일은 서버가 막아서 직접 확인하지 못했다.
- 시세 나열 섹션만 단지마다 사진 1장 + 텍스트 1블록을 반복했다 (4회).
- 캡션은 5편 모두 0개다. → 우리 5-7(절반에 캡션 + 키워드)과 다르다. 캡션 쪽이 키워드 노출에 유리하므로 우리 규칙을 유지한다.
