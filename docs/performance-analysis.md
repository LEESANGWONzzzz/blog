# 성과 분석 방법 — 상위 글의 교집합 찾기

> 참고: 사용자가 공유한 다른 블로거의 글 「네이버 블로그 꿀팁 1탄」의 분석 방법을 이 도구에 맞게 옮긴 것이다.
> 원문 문장은 옮기지 않았다. 원문에 나온 수익 수치(월 애드포스트 약 150만 원, 하루 1만→7만 원)는 원문 작성자의 주장이며 검증되지 않았다.

## 핵심 아이디어

남의 블로그가 아니라 **내 블로그의 성과 데이터**를 본다.
조회수 상위 글들에서 **겹치는 것(교집합)**을 찾고, 그 조합으로 다음 글을 쓴다.

교집합을 찾는 네 가지 축:

| 축 | 이 도구에서 보는 값 |
|---|---|
| 제목 스타일 | `title_hook` (숫자형 / 비교형 / 손실회피형 / 질문형 / 반전형), 제목 길이, 숫자 포함 여부 |
| 키워드 단어 | 제목에 나온 단어, `keywords.main` |
| 후킹 문구 | `hook_pattern` (도입부: 손실회피형 / 현장몰입형 / 반전형 / 공감형) |
| 글 전체 스타일 | 이 블로그는 화자 목소리를 하나로 고정했다 (`writing-rules.md` 4절) — 아래 "원문과 다른 점" 참고 |

## 절차

1. **글을 먼저 쌓는다.** 교집합은 표본이 있어야 보인다. 최소 10개, 가능하면 20개 이상.
   쌓는 동안 `title_hook`과 `hook_pattern`을 일부러 섞어 쓴다. 한 유형만 쓰면 비교할 대상이 없다.
2. **네이버 크리에이터 어드바이저**에서 조회수 순위를 본다. (원문 기준 메뉴: 통합데이터 → 조회수 순위)
   1위부터 20위까지 본다. 글이 많으면 30~40위까지 봐도 된다.
3. **제목과 조회수를 `data/performance.csv`로 옮긴다.** 첫 줄은 머리글이다.
   ```
   제목,조회수
   2026 연금저축 세액공제 한도 직장인이 놓친 조건,"1,234"
   ```
   쉼표가 들어간 숫자는 따옴표로 감싼다. 사람이 직접 옮긴다 (자동 수집하지 않음).
4. Claude Code에서 `/analyze`를 실행한다. 이 명령은 아래 스크립트를 실행하고 결과를 해석한다.
   ```
   node scripts/analyze_performance.js data/performance.csv
   ```
   결과는 `data/analysis-latest.md`에 저장된다.
   - 상위 30% 글(최소 3개)과 나머지를 나눠 제목 유형·도입 후킹별 평균 조회수를 비교한다.
   - 상위 글 2개 이상에 나온 단어를 교집합 후보로 뽑는다.
   - 이 도구로 쓴 글은 `drafts/`의 초안 정보(`title_hook`, `hook_pattern`, 키워드)와 제목으로 연결한다. 연결되지 않는 글은 제목만 보고 유형을 **추정**한다.
5. **교집합으로 다음 글을 쓴다.** `/write`가 `data/analysis-latest.md`를 읽고 제목 유형과 키워드 후보에 반영한다.
6. **1~2일 뒤 결과를 보고 다시 분석한다.** 같은 CSV에 새 글을 추가하고 4번부터 반복한다.

## 원문과 다른 점 (이 블로그의 규칙 때문에)

| 원문 | 이 도구 | 이유 |
|---|---|---|
| 글 스타일(존댓말 / 언론기사체 / 경험담 공유형)을 섞어 보고 잘 된 쪽을 따른다 | 화자 목소리는 `~해요`체 경험담형으로 고정. 대신 제목 유형·도입 후킹을 섞는다 | `writing-rules.md` 4절이 목소리를 단일 기준으로 정함. 바꾸려면 규칙 개정이 먼저 필요 (사용자 결정) |
| 일단 많이 써서 쌓는다 | 자동 임시저장은 하루 1~2건 | 네이버 약관상 자동화는 회색지대 (`CLAUDE.md` 안전 규칙). 사람이 직접 쓰는 글은 제한 없음 |
| 교집합 조합으로 파생 글을 쓴다 | 단어·유형만 가져오고 문장은 새로 쓴다. 같은 제목 틀을 연속으로 쓰지 않는다 | 유사문서 판정 위험 |
| 조회수가 터진 글을 따라 쓴다 | 사실 자산·수치 확인 규칙은 그대로 적용 | 조회수를 이유로 사실을 지어내지 않음 |

## 해석할 때 주의

- **상관관계이지 원인이 아니다.** 같은 제목 유형이라도 발행 시점, 시즌(연말정산 시기 등), 홈판 노출 여부, 검색 유입 경로가 결과를 크게 바꾼다.
- **표본이 작으면 우연이 크다.** 글 10개 미만에서 나온 교집합은 참고만 한다.
- 조회수와 수익(애드포스트)은 다른 지표다. 수익 기준으로 보고 싶으면 CSV에 열을 추가해 따로 봐야 한다 (현재 스크립트는 조회수만 본다).
