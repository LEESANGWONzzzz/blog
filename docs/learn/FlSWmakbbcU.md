# 영상 학습 노트 — "하루 1시간만에 끝냅니다" 월 100만원 버는 블로그 1시간 루틴

- 링크: https://youtu.be/FlSWmakbbcU
- 채널: 네이버 블로그 오리나 · 업로드 2026-10-09 · 길이 약 11분 20초
- 설명란: 제목 한 줄뿐 (출처·자료 링크 없음)
- 자료: 한국어 자동 생성 자막만 사용 (영상 화면은 보지 않음). 자막 원본 `.vtt`는 커밋하지 않음
- 정리일: 2026-10-11

## 1. 요약

퇴근 후 1시간에 글 5편을 쓰는 루틴을 소개한다. 순서는 다음과 같다.

1. 주제를 **방송연예 하나로 고정**한다 (매일 분야를 바꾸면 공부하다 시간이 끝남). 오래된 사건 정리나 드라마를 직접 봐야 하는 글은 뺀다.
2. 키워드 후보는 두 곳에서 찾는다.
   - **크리에이터 어드바이저 → 스타·연예인 트렌드 → 주제별 인기 유입 검색어**
   - **네이버 엔터판 → 최신 뉴스 탭**: 남들이 아직 많이 안 쓴 최신 이슈를 잡는다
3. 제목은 운영자가 배포하는 "제목 프롬프트"(이득형·손해형·위협형)에 예시 제목을 넣어 GPT로 뽑는다.
4. 본문은 "본문 프롬프트"에 **이미 적혀 있는 관련 본문을 붙여 넣어** GPT로 쓰고, 소제목째 복사·붙여넣기한다. 한 편에 5분.
5. 1시간 틀: 소재·키워드 5개 10분 → 자료·사진 15분 → 작성·수정 편당 5분(25분) → 검수(팩트·제목·해시태그) 10분.
6. 자동화 한계: AI에게는 **글쓰기만** 맡긴다. 키워드 찾기·사진 찾기·발행까지 자동화하면 "네이버가 알아채고 아이디를 정지한다".
7. 로드맵: 1달 데이터 쌓기 → 2달 시간 단축 → 3달부터 수익. 블로그를 여러 개 키워 애드포스트를 합쳐 월 100만 원.
8. 프롬프트는 영상에 공개하지 않고, 좋아요·댓글을 달면 고정 댓글 링크로 준다고 한다.

## 2. 핵심 주장 판정

판정 기준
- **근거 있음**: 공식 도구나 공개된 사실로 확인되거나, 영상 안에서 실제 화면·과정을 보여 준 것
- **주장일 뿐**: 그럴듯하지만 데이터나 출처 없이 말로만 한 것
- **확인 불가**: 사실 여부를 판단할 자료가 없는 것

| # | 주장 | 판정 | 메모 |
|---|---|---|---|
| 1 | 크리에이터 어드바이저 트렌드 메뉴에서 주제별 인기 유입 검색어를 볼 수 있다 | 근거 있음 | 네이버 공식 도구이고 자막상 화면을 보며 시연함 |
| 2 | 엔터판 "최신 뉴스" 탭에서 아직 덜 쓰인 이슈를 잡으면 더 빨리 번다 | 주장일 뿐 | 선점 효과의 조회수 데이터는 없음 |
| 3 | 주제를 한 분야로 고정하면 조사 시간이 줄어든다 | 주장일 뿐 | 상식적이지만 측정값은 없음 |
| 4 | 제목 프롬프트(이득형·손해형·위협형)로 후킹 제목을 뽑을 수 있다 | 확인 불가 | 프롬프트 내용이 공개되지 않음 (댓글 조건부 배포) |
| 5 | 기존 본문을 붙여 넣고 본문 프롬프트를 돌리면 한 편이 5분에 끝난다 | 주장일 뿐 | 시연은 했다고 하나 품질·유사문서 판정 결과는 없음 |
| 6 | 한 달 연습하면 한 편에 5분도 안 걸린다 | 주장일 뿐 | 개인 경험담 수준 |
| 7 | AI에 넘기는 자료가 재밌고 정확해야 조회수가 뜬다. 관심 없는 글은 하루 20~30편을 써도 못 번다 | 주장일 뿐 | 우리 규칙과 같은 방향. 근거 데이터는 없음 |
| 8 | 키워드·사진·발행까지 자동화하면 네이버가 감지해 아이디를 정지한다 | 확인 불가 | 네이버 공식 기준이나 사례 인용 없음. 다만 우리 안전 규칙과 같은 방향이라 보수적으로 받아들임 |
| 9 | 블로그 여러 개를 키워 애드포스트를 합치면 월 100만 원에 빨리 도달한다 | 주장일 뿐 | 수익 인증·계정 수 같은 수치 없음 |
| 10 | 1달 데이터 → 2달 단축 → 3달 수익 | 주장일 뿐 | 일정 근거 없음 |
| 11 | 화자는 본업·사업·강의를 하면서도 이 방식으로 많은 글을 쓴다 | 확인 불가 | 자기소개 |

## 3. 우리 규칙과 비교

### 맞는 것
- **발행은 사람이 한다** (주장 8) — CLAUDE.md 안전 규칙 "발행·예약 버튼은 운영자가 누른다", `publish_guard.js`와 같은 방향이다.
- **글 수보다 소재의 질** (주장 7) — writing-rules 5-6(AI 브리핑 인용), 6절(수치 무결성)과 같은 방향이다.
- **마지막 검수 단계에 팩트·제목·해시태그 확인** — 우리는 `lint_draft.js` + `review.md` + `publish_checklist.txt`로 이미 하고 있다.
- **데이터를 쌓고 잘 되는 키워드·제목에 집중** (주장 10) — `/analyze`와 writing-rules 8절이 같은 일을 한다.
- **한 분야로 시간 아끼기** (주장 3) — 우리는 이미 "생활경제" 한 분야다 (안의 5개 소분류는 균등 배분).

### 충돌하는 것
| 영상 | 우리 규칙 | 판단 |
|---|---|---|
| 방송연예로 주제 전환 | writing-rules 1절: 주제는 생활경제. 프로필: 5개 소분류 균등 | 따르지 않는다. 블로그 정체성과 AI 브리핑 목표가 바뀐다 |
| 기존 본문(기사·남의 글)을 붙여 넣고 AI로 재작성 | 5-5 "문장·문단 순서·이미지는 새로 만든다", 3절 사실 자산, 5-8 "다른 블로그·뉴스 사진 금지" | 따르지 않는다. 유사문서 저품질 위험이 크고 사실 확인 경로가 사라진다 |
| 블로그 여러 개 운영 | CLAUDE.md "본인 계정만 쓴다" | 따르지 않는다. 다중 계정은 운영자 결정이고, 이 도구는 지원하지 않는다 |
| 하루 5편 이상, 시간 단축해 계속 늘리기 | 프로필: 하루 4편(2026-10-07 결정, 1~2주 뒤 조정). `dailySaveLimit`는 운영자 결정 | 편수 확대를 제안하지 않는다. 1~2주 운영 데이터를 보고 운영자가 정한다 |
| 한 편 5분 (AI 출력 복사·붙여넣기) | 6절: 수치는 공식 자료로 직접 대조, 확인 못 하면 저장 불가 | 속도보다 검증이 우선. 우리 쪽이 시간이 더 드는 건 의도된 비용 |
| 키워드 찾기 자동화 = 정지 위험 (주장 8) | 우리 `/auto`·`/daily`는 주제 선정과 이미지 생성을 Claude가 한다. 임시저장도 브라우저 자동화로 한다 | 아래 4-3 참고. 영상 주장은 확인 불가지만 위험 신호로 기록해 둔다 |

## 4. 반영 제안 (규칙 파일은 아직 고치지 않음)

### 4-1. 넣을 만한 것
1. **크리에이터 어드바이저 트렌드를 키워드 후보 입력으로 쓰기** (`/daily` 1번)
   - 운영자가 크리에이터 어드바이저의 "비즈니스·경제" 트렌드 상위 검색어를 직접 보고, 몇 개를 `/daily` 인자로 붙여 넣는다.
   - Claude가 크리에이터 어드바이저를 자동으로 긁지는 않는다 (로그인 도구 자동 조회는 계정 위험, CLAUDE.md 크롤링 금지 취지).
   - 효과: "최근 7일 공공기관 발표"만으로 고르던 주제에 실제 검색 수요 신호가 더해진다.
2. **"최신 이슈 선점"의 우리 판 — 공식 발표 당일 해설** (`경제 뉴스 해설`·`정책·지원금` 카테고리)
   - 엔터판 최신 뉴스 대신 한국은행·통계청·기획재정부 보도자료가 나온 날 그 원문으로 쓴다.
   - 기사 본문을 붙여 넣는 방식이 아니라 기관 원문 수치를 6절대로 대조한다.
3. **저녁 루틴 시간 상자** (`/daily` 보고에 추가)
   - 영상의 10/15/25/10분 틀처럼 단계별로 걸린 시간을 보고에 한 줄 남긴다 (주제·수치 확인·작성·저장).
   - 목적은 편수 확대가 아니라 자정 마감(프로필 작업 루틴)을 지키기 위한 병목 찾기.
4. **제목 유형 대응표만 참고**
   - 영상의 이득형·손해형·위협형은 우리 `title_hook`의 숫자형·손실회피형과 겹친다. 새 유형을 추가하지 않고, `/analyze` 결과로 판단한다.
5. **한 달 데이터 → 집중** 로드맵은 `/analyze` 실행 주기로 반영 가능
   - 예: 발행 글 10편 이상이 되면 주 1회 `/analyze`. (8절 "10개 미만이면 참고만"과 맞춤)

### 4-2. 넣지 말아야 할 것 (계정 위험·규칙 충돌)
- **남의 글·기사 본문을 붙여 넣어 AI로 재가공** — 유사문서 저품질, 저작권, 사실 확인 경로 소실.
- **블로그 여러 개 운영·다중 계정 자동 저장** — "본인 계정만" 규칙 위반.
- **자동 발행·자동 예약** — 안전 규칙. `publish_guard.js` 유지.
- **자동 댓글·자동 공감·자동 이웃 추가** — 영상에는 없지만 같은 범주의 자동화. 계정 정지 위험이 가장 큰 행동이라 도입하지 않는다.
- **하루 저장 편수 늘리기** — `dailySaveLimit`는 운영자 결정. 영상의 "5편 이상"은 근거가 아니다.
- **연예 이슈로 주제 확장** — 블로그 정체성·AI 브리핑 목표와 맞지 않는다.
- **댓글 조건부 "제목·본문 프롬프트" 받아 쓰기** — 내용이 검증되지 않았고, 우리 정본(writing-rules)과 섞이면 규칙이 흐려진다.

### 4-3. 짚어 둘 위험 (영상 주장 8 관련)
영상은 "글쓰기만 AI, 나머지는 사람"을 말한다. 우리 도구는 그보다 더 자동화돼 있다.

- 주제 선정과 이미지 생성은 Claude가 한다 (`/auto`·`/daily`).
- 임시저장은 브라우저 자동화(`naver_draft.js`)로 한다.

발행은 사람이 하고, 저장 수 상한이 있고, 크롤링을 하지 않는다. 그래서 영상이 말한 "전부 자동화"는 아니다.
다만 정지 기준이 공개돼 있지 않으니(확인 불가), 지금 쓰는 안전장치(`dailySaveLimit`, 발행 가드, 크롤링 금지, 1회 검증)를 느슨하게 하지 않는 쪽을 권한다.
