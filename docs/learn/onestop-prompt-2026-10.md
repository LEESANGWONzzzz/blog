# 운영자가 준 "반자동화 원스톱" 프롬프트 반영 기록 (2026-10-18)

운영자가 붙여 넣은 프롬프트(주제 조사 → 완성 원고 → 이미지 3장 → 최종 검수, 발행은 사람이)를 항목별로 기존 규칙과 대조했다.

| 프롬프트 항목 | 우리 쪽 상태 | 반영 |
|---|---|---|
| 1. 대상 독자 = 초보자, 쉽고 정확하게 | 페르소나(5-2)는 있었지만 용어 풀이 규칙은 없었음 | 5-12: 어려운 용어는 첫 등장 때 한 줄 풀이 |
| 2. 공식 자료 우선·최신 조사 | 이미 있음 (6절, `auto.md` facts.md) | 그대로 |
| 2. 기존 글과 중복 피하기 | 이미 있음 (`daily.md` 제외 주제) | 그대로 |
| 2. 날짜·가격·쿠폰·이벤트 조건 검증, 미확인 표시 | 이미 있음 (`[[확인필요]]`면 저장 안 함) | 5-12: 검수 보고에 "미확인" 목록 |
| 2. 검색하지 않았으면 했다고 주장 금지, 성과 보장 금지 | 명시 안 됨 | 5-12에 명시 |
| 2. 후보 길게 나열 말고 하나 선택 | `/daily`는 여러 편 | 새 `/today`: 1편만 고르고 후보 목록 보고 안 함 |
| 3. 완성 원고 (제목~해시태그) | draft.json → 임시저장, 태그 문단 자동 | `export_manuscript.js`로 복사용 원고도 남김 |
| 3. 사람 말투, `~습니다` 반복 최소화 | `~해요`체 + 수치는 `~입니다` | 5-12: `~입니다·~습니다` 두 문장 연속 금지 |
| 3. 일반 문장 2~4문장씩 | 2문장 고정이었음 | **2~3문장**으로 완화 (모바일 가독성 때문에 4는 안 함), lint도 3 초과일 때만 경고 |
| 3. 서론 짧게, 핵심 구체적으로 | Yes-set·권위 한 줄 | 5-12: 세 문단 안에 서론 끝내기 |
| 3. 경험·후기 지어내지 않기 | 이미 있음 (2·3절) | 그대로 |
| 3. 마크다운 기호 금지 | 규칙 없음 | lint 오류로 막음 (`**`, `##`, 백틱) |
| 3. 출처 포함 | 문장 안 기관명·기준일만 | 면책 앞 `출처:` 문단 (lint 경고) |
| 3. 해시태그 마지막 줄 | 이미 있음 (임시저장 때 자동) | 원고 파일도 마지막 줄이 태그 |
| 3. [이미지 n 삽입] 표시 | 에디터에 실제 사진을 넣음 | 원고 파일에 `[이미지 n 삽입]`으로 표시 |
| 4. 이미지 3장: 대표·설명·활용, 별도 파일, 콜라주·자르기 금지 | 카드 4~8장(표지·요약·마무리) | 5-12: 세 역할 최소 1장씩, 별도 파일 |
| 4. 글자 잘림 방지, 문제 이미지만 수정 | 카드 넘침은 `make_cards.js`가 이미 오류로 막음 | 그대로 + Read로 장마다 확인 |
| 4. 못 만든 이미지 완료 주장 금지 | 명시 안 됨 | 5-12에 명시 |
| 5. 최종 검수 ①~⑦ | review.md 형식(7-2) | `/today` 7번에 ①~⑦ 체크를 review.md 끝에 기록 |
| 6. 발행·예약 금지 | 이미 있음 (발행 가드) | 그대로 |
| "오늘 글 작성해줘" → 원스톱 | 없음 | CLAUDE.md에 연결 → `/today` |

## 반영하지 않은 것

- **블로그 분야·대상 독자 입력칸**: 이미 `data/blogger-profile.md`에 있다.
- **이미지 정확히 3장**: 우리 규칙은 4~8장이다 (모바일 리듬, 5-5·5-7). 3장은 "최소 역할 수"로만 받아들였다.
