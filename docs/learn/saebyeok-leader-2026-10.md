# "새벽리더" 블로그 수익화 사례 요약 정리 (2026-10-19)

운영자가 붙여 넣은 요약글을 기준으로 정리했다. 원 출처(영상·강의)는 보지 않았고, 수치(23일 만에 하루 1만 명, 월 300만 원, 원고료 건당 10만~20만 원)는 본인 주장이라 검증할 수 없다.

## 핵심 주장 3가지

1. **나·업체를 위한 글에서 읽는 사람을 위한 글로.** 체험단 중소업체 제품 리뷰는 검색 유입이 거의 없었다. 검색량은 많은데 문서 수가 적은 키워드(예: 구독 해지법·탈퇴법)를 매일 쓰자 유입이 크게 늘었다고 한다.
2. **이웃 품앗이(서로이웃·답방·공감)를 끊었다.** 그 시간을 글 생산에 썼다. 수익의 바탕은 검색·홈판 방문자라는 판단이다.
3. **방문자가 일정 수준을 넘자 원고료 제안이 늘었다.** 원고료는 1~3달 뒤에 정산되므로 바로 돈이 안 들어와도 버텨야 한다고 한다.
4. (덧붙임) 지금의 홈판은 새 계정도 제목과 관심사가 맞으면 노출 기회가 있다. AI로 뼈대를 잡되 그대로 붙여 넣지는 않는다.

## 우리 블로그에 반영한 것

| 내용 | 반영 |
|---|---|
| 검색량 대비 문서 수가 적은 키워드 | `scripts/keyword_score.js` 새로 만듦 — **네이버 공식 API**로 월간 검색량(검색광고 키워드도구)과 블로그 문서 수(검색 API total)를 대조해 경쟁도 순으로 정리. `/daily`·`/today`의 09·19시 검색형 칸이 먼저 참고 (writing-rules 5-11) |
| 품앗이 중단 | 이미 5-11에 금지 규칙이 있었는데, 임시저장 체크리스트 5번이 "방문 댓글(이웃 늘리기)"을 권하고 있어 서로 어긋났다 → 체크리스트를 "내 글 댓글 답글만, 시간 날 때"로 바꿈 |
| 홈판 기회 | 이미 반영 (07·17시 홈판형, 5-11) |
| AI로 뼈대, 복붙 금지 | 이미 반영 (사실 대조·AI 냄새 점검표) |

## 따르지 않은 것

- **"키워드 챌린지에서 수천~수만 개 키워드를 통째로 긁어모으기"**: 화면을 자동으로 긁는 방식은 CLAUDE.md의 수집 금지 규칙과 네이버 robots.txt에 걸린다. 같은 목적을 공식 API(검색광고·검색 API)로 대신한다.
- **댓글 답글까지 끊기**: 근거가 이 사례 하나뿐이다. 내 글 댓글 답글은 선택으로 남겼다.

## 확인할 점

- 프로필의 목표 "이웃 1,000명"은 품앗이를 끊으면 느리게 오를 수 있다. 목표를 유지할지는 운영자 결정이다.
- 원고료 제안이 오면 협찬 표시 규칙(5-10)을 따른다. 금융 상품(예금·대출·보험·투자) 원고료 광고에는 금융 광고 관련 별도 규제가 있을 수 있으나 아직 확인하지 않았다 — 제안이 오면 먼저 확인한다.
- `keyword_score.js`가 쓰는 API 사양은 공식 문서로 확인했다 (검색광고 API `ncc-keywordstool.json`·공식 Python 샘플 서명 방식, developers.naver.com 블로그 검색 API, 하루 25,000회 한도). 실제 키로 돌려 보지는 않았다.
