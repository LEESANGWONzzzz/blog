## 그대로 따르지 않는 것

- **남의 계정 게시물 20개를 Apify로 수집해 "복사"하기** (beucheo.ai): 인스타 robots.txt는 Instagram의 서면 허락 없는 자동 수집을 금지한다 (2026-10-30 직접 확인). 우리 CLAUDE.md "타인 콘텐츠 자동 수집 금지"와도 부딪친다. 쓰지 않는다. 운영자가 직접 본 화면을 캡처해 주는 방식(이번 PDF)만 쓴다.
- **"댓글에 ○○ 남기면 DM으로 자료 보내드려요"** (platformtree · beucheo.ai · highoutputclub): 반응을 끌어올리는 흔한 방식이다. 다만 인스타가 이런 유도를 어떻게 평가하는지는 확인 불가다. 쓰려면 실제로 보낼 자료(블로그 글 링크 등)가 있을 때만, 운영자가 직접 DM을 보낸다. 자동 DM 도구는 붙이지 않는다.
- **"핵심을 바로 주지 마라"** (31brand Rule #2): 인스타 체류 전략으로는 이해하지만, 같은 정보를 블로그에서는 "결론 먼저"(AI 브리핑 5-6)로 쓴다. 인스타 카드에서도 표지가 약속한 답은 늦어도 3~4장 안에 준다 (낚시 금지).
- **특정 계정의 디자인 복제**: 손글씨 노트(platformtree), 검정+분홍(31brand), 흰색+주황 캐릭터(beucheo.ai), 파란 프레임(highoutputclub)은 각 계정의 식별 요소다. 원리만 가져오고 색·글꼴·캐릭터는 우리 것으로 정한다.

## 우리 인스타 카드뉴스 기본안 (Claude 추천, 운영자가 바꿀 수 있음)

- 재료: 이미 **발행된** 블로그 글의 draft.json (확인된 숫자·출처가 이미 있음). 새 사실을 추가하지 않는다.
- 크기 1080×1350, 7장:
  1. 표지 — 질문형 제목 12~20자 + 핵심 숫자 1개
  2. 문제 공감 — "이런 분" 한 줄 + 손해·마감 같은 결과
  3. 핵심 답 — 블로그 첫 소제목의 결론 (숫자·기관·기준일)
  4. 방법 1 — 신청·확인 순서 (steps)
  5. 방법 2 — 조건·대상 비교 (compare 또는 table)
  6. 주의·추가 인사이트 — 놓치기 쉬운 조건 1개 + 출처 줄
  7. CTA — 계정 약속 한 줄 + "자세한 계산은 블로그" 안내
- 캡션: 첫 줄 훅 → 3줄 요약 → 출처(기관·기준일) → 블로그 안내 → 해시태그 5~10개.
- 시리즈: 블로그에서 반응이 좋았던 주제를 5편으로 나눈다 (각 편 단독으로도 유용하게, 다음 편 예고 한 줄).
- 업로드는 운영자가 직접 한다.

## 이미지 (2026-10-30 운영자 요청: 글만 있으면 흥미가 없다)

- **글에 실제로 들어간 이미지만 다시 쓴다**: 직접 찍은 모자이크 사진(`input/photos/_mosaic/`)·AI 일러스트는 표지 사진으로, 각 소제목 구간에 있던 이미지(정보 카드·공공누리 자료 등)는 그 Q 카드에 넣는다. 캡션에 "출처"가 있으면 이미지 구석에 그대로 표시한다.
- **이미지가 없는 장은 직접 그린 아이콘**(달력·동전·서류·집·티켓·카드·저금통·주의·그래프·쇼핑백·그릇·마이크·체크)을 문장 키워드로 골라 넣는다. 외부 이미지가 아니라 저작권 문제가 없다. 같은 아이콘이 이어지지 않게 고른다.
- 검색으로 찾은 남의 사진·연예인 사진·브랜드 사진은 넣지 않는다 (writing-rules 5-8·5-9·5-10과 같다).

## 형식 변경: 데일리 브리핑 (2026-10-30 운영자 결정)

주제별(글 1편 = 1세트) 대신 **날짜별 1세트**로 바꾼다. 매일 6편을 신문 한 부처럼 묶는다 (`scripts/insta_daily.js`).

- 1면: 마스트헤드(블로그 이름·날짜·요일) + "월급날 브리핑" + 대표 사진(글 속 직접 찍은 사진·AI 일러스트) + 오늘의 이슈 목록(번호·카테고리·제목)
- 이슈 1장씩: ISSUE 번호·카테고리 → 헤드라인(글 제목) → Q(첫 소제목) → 글 속 이미지(없으면 아이콘) → 핵심 문장 2~3개(첫 소제목 바로 뒤 답, 빨간 세로줄)
- 마지막 장: 오늘 챙길 것(글마다 ✔ 체크리스트 첫 항목, 최대 5개) + 블로그 안내 + 기준일
- 디자인: 신문지 바탕(미색 + 망점), 굵은 이중 괘선, 명조 헤드라인, 빨강 포인트. 앞의 3테마(mint·night·purple)는 글별 세트(`insta_cards.js`)에만 남긴다.
- 캡션: "○월 ○일 월급날 브리핑 — 오늘의 이슈 n" + 제목 목록 + 기준일 안내 + 태그(글 태그 합쳐 최대 10개).
