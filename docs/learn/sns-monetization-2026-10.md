## 2. 우리 블로그에 맞는 것 / 충돌하는 것

### 이미 하고 있는 것
- 대중 주제 확장: 07 방송·연예, 17 패션·미용/맛집·외식, 09 생활경제·정책 (10/17~10/30 실험)
- 크리에이터 어드바이저 트렌드 검색어를 `/daily` 입력으로 받기
- 구어체(~해요), 자동 품앗이 금지

### 새로 반영한 것 (`docs/writing-rules.md` 5-11, `/daily`)
1. **두 트랙 구분** — 07·17시는 "홈판형"(실시간 화제·각도·공감), 09·19시는 "검색·AI 브리핑형"(질문형 소제목·완결 문장). 목표 1(AI 브리핑)을 버리지 않는다.
2. **각도 비틀기** — 홈판에 뜬 주제를 그대로 쓰지 않고 "다들 놓친 한 가지 질문"으로 비튼다. 단, 제목에서 던진 질문의 답을 본문 첫 부분에 주고, 확인된 사실 안에서만 비튼다.
3. **AI 냄새 점검표** — 저장 전 스스로 점검 (아래 5-11).
4. **다포** — 메가 이슈는 같은 날 최대 2편, 서로 다른 질문일 때만. 3편 이상은 하지 않는다.
5. **메인 유입 트렌드 1~20위** 캡처·검색어를 운영자가 `/daily`에 함께 넘긴다.

### 반영하지 않는 것
- 홈판에 뜬 남의 글 구조를 따라 쓰기 (각도만 참고, 문장·구성은 새로) — 유사문서 위험
- 물음표·과장형 낚시 제목 — 현재 제목 규칙(특수문자 금지)과 충돌. 바꾸려면 운영자 결정 필요
- 확인 안 된 "블로그 지수 무시" 주장에 기대 발행량을 늘리는 것 — 저장 상한 유지
- 수익 수치를 목표 근거로 쓰는 것
