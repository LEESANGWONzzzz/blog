# 네이버 공식 "AI 시대 콘텐츠 작성 가이드"와 모찌앤잡 GPT 설정 페이지 정리 (2026-10-30)

2. 네이버 검색 공식 블로그 원문 (blog.naver.com/naver_search/224296857688) — **직접 열지 않았다.** blog.naver.com의 robots.txt가 AI 봇 접근과 RAG 이용을 금지하고 있어서 (2026-10-18 확인), 대신 같은 가이드를 다룬 언론 보도로 확인했다.
   - MTN 보도 (다음뉴스, 2026-06-17): "AI가 읽고 인용한 글에 상금…네이버, 창작자 보상 실험"
   - 더팩트 보도 (네이트뉴스, 2026-05-29): 네이버 메이트 선정 기준

## 공식 가이드 핵심 (보도 기준)

- 한 문장 요약: **창작자만의 맥락과 경험이 담긴 콘텐츠**. 직접 겪은 이야기, 시행착오에서 얻은 통찰, 개인의 취향·감정·관점이 담긴 해석을 지향한다.
- AI 브리핑 인용 가능성을 높이는 원칙 5가지: 직접 경험한 지식 · 일관된 주제 · 거짓 없는 진정성 · 읽기 쉬운 구조 · 최신성.
- 마이너스 요인: 무분별한 복제와 생성 · 과도한 광고와 홍보 · 무관한 키워드 삽입 · 콘텐츠와 무관한 이미지와 동영상 · 부정확하고 부적절한 정보.
- "AI 도구를 활용해 작성했다고 해서 불이익을 받는 것은 아니다", 다만 최종 검토·편집으로 창작자의 경험이 반영되는 게 중요하다.
- 네이버 메이트: AI 브리핑 인용수가 주요 선정 기준. 2026년 12월까지 베타, 월 단위 선정. 1기는 100명 300만 원·10명 1,000만 원(MTN 보도). 하반기 "AI 탭" 인용수도 반영 예정.

## 모찌앤잡 지침 8가지와 우리 규칙 대조

| 지침 | 우리 쪽 |
|---|---|
| 쓰기 전에 경험(가봤는지, 좋았던 점·아쉬웠던 점)을 묻고, 답한 것만 쓴다 | `/daily`는 무인 실행이라 미리 묻지 않는다. 대신 "운영자 한 줄"(owner_note_prompt)로 예약 때 직접 넣는다. 경험 창작 금지는 이미 있음 |
| 가격·날짜·수치는 준 자료·공식 페이지만, 모르면 [확인 필요] | 이미 있음 (6절, `[[확인필요]]`면 저장 안 함) |
| 베끼기·짜깁기 금지, 같은 내용을 표현만 바꿔 여러 편 금지 | 베끼기 금지는 있음. "표현만 바꿔 재탕 금지"를 5-12에 추가 |
| 검색어는 맥락에 맞을 때만 | 이미 있음 (키워드 5~7회 상한, 홈판형은 반복 안 함) |
| 협찬 표시는 맨 위, 인용 출처 표기 | 이미 있음 (5-10, 출처 문단) |
| 소제목·문단 나누기, 사진 속 핵심 정보는 글로도 | 앞부분은 있음. "카드 정보는 본문 문장으로도"를 5-12에 추가 |
| 광고 문구·바깥 링크는 필요한 곳에만 | 이미 있음 (업체명은 CTA 1회) |
| 끝에 [확인 필요] 목록과 직접 확인할 부분 정리 | 이미 있음 (review.md 수치 출처표·미확인 목록) |

## 새로 반영한 것 (writing-rules 5-12 "네이버 공식 가이드 대조")

- 문단과 상관없는 장식용 이미지 금지 (공식 마이너스 요인).
- 카드에만 있는 정보 금지: 카드의 숫자·조건·순서는 본문 문장으로도.
- 같은 주제 재탕 금지: 후속 발표로 새 질문이 생길 때만 다시 쓴다.

## 운영자에게 남기는 판단거리

- 공식 원칙에 **"일관된 주제"**가 들어 있다. 지금 블로그는 경제(검색형)와 연예·패션·맛집(홈판형)을 섞고 있어 이 원칙과 부딪칠 수 있다. 홈판 사례들(`homefeed-cases-2026-10.md`)도 "섞지 말라"고 했다. 시험 편성이 10/30에 끝나니, 평가 때 계정 분리 여부를 함께 정하는 것이 좋다.
- 하루 6편을 AI로 만드는 구조는 "무분별한 생성"으로 보일 위험이 있다. 운영자 한 줄과 사실 대조가 그 위험을 줄이는 장치다. 한 줄을 넣은 글과 안 넣은 글을 기록해 두면 효과를 볼 수 있다.
