# 키워드 확장·제휴 수익화·소재 선점 (2026-11-14, 운영자가 붙여 준 글 3개)

> 세 글 모두 남의 주장이다. "월 1000만원", "5번째 블로그 성공", "월 수백만 원 커미션"은 검증하지 못했다.

## 원문 요지
**A. 월 1000만원 키워드 전략**
- 기사처럼 사건을 요약하지 말고, 사람들이 검색창에 넣는 꼬리 키워드에 답하는 글을 쓴다. 메인 키워드 + ㄱ·ㄴ·ㄷ…을 넣어 연관검색어를 수십 개 뽑아 쪼개서 발행.
- 루머를 단정하지 말고 공식 정보로. 트래픽이 모이는 글 끝에 제휴 링크를 단다.
- 예시 5개: 김장 재료(쇼핑 커넥트) / 수능 선물(쇼핑 커넥트) / 젠슨 황 국적·나이·부인·프로필(애드포스트) / 비짓재팬웹(유심·와이파이·여행자보험 제휴) / 트립닷컴 할인코드(숙박 제휴).

**B. 홈판 꿀팁**
- 벤치마킹 블로그 5곳의 인기글을 캡처 → "이런 형식의 프롬프트를 만들어 줘, 그대로 베끼면 안 돼" → 하루 3~5편 꾸준히.
- 가장 중요한 것은 소재 선점: 정기 방송(예: 수요일 방송)은 방송일 전후로 쓴다. 바로 안 떠도 관련 글을 쌓아 두면 홈판에 오래 걸린다.
- 글 내용은 다들 좋아졌으니 차이는 제목 후킹과 소재 선택·선점.

**C. 메모 (패션 한 주제 + 무신사 큐레이터)**
- 연예인·연예인 패션 한 주제로 밀기, 무신사 큐레이터 연계, 스레드 글 자동화.

## 확인한 것 (2026-11-14)
- 무신사 큐레이터: 승인된 인플루언서가 SNS에서 무신사 상품을 소개하고 매출이 나면 수수료를 받는 제휴 서비스. 2024년 7월 베타 시작, 누적 거래액 1,200억 원 돌파 보도(2025-12, 헤럴드경제·무신사 뉴스룸). 수수료 "최대 10% 이상" 보도. **가입 조건·활동 가이드·광고 표시 문구는 확인 못 함** (큐레이터 공식 안내에서 확인 필요).
- 나머지 수익 주장은 확인 불가.

## 우리 규칙과 대조

| 수십 개로 쪼개 발행 | **제한**: 같은 이슈는 하루 최대 2편(다포), 다른 날 이어 쓸 때도 질문이 달라야 함. 표현만 바꾼 쪼개기는 유사문서 |

| 하루 3~5편 | 지금 6편 |

## 운영자 판단거리 — "연예인 패션 한 주제 + 무신사 큐레이터"
- 맞는 점: 11/2 주 조회 상위에 브랜드·패션 가격 글이 5편. 레퍼런스 블로그도 셀럽 패션이 가장 큰 칸. 큐레이터 수수료라는 수익원이 생김.
- 걸리는 점 ① 연예인 사진을 쓸 수 없다 (초상권·저작권, 5-9). 셀럽 패션 블로그의 핵심이 착용 사진이라 정보 카드만으로는 약함 ② 착장 정보는 브랜드·소속사가 공식으로 밝힌 것만 쓸 수 있어 소재가 제한됨 ③ 블로그 이름·지금까지 쌓은 글이 "월급·경제"라 주제를 통째로 바꾸면 일관성이 깨짐 ④ 스레드 자동 게시는 플랫폼 약관 확인 전에는 하지 않음.
- 제안: 통째로 바꾸지 말고 **17시 칸을 "브랜드 가격·패션" 고정**으로 2주 시험하고 큐레이터 링크를 붙여 본다 (승인되면). 조회·수수료가 나오면 그때 비중을 늘리거나 패션 전용 블로그를 따로 만든다.
