---
description: 내 블로그 조회수 상위 글의 교집합(제목 유형·후킹·단어)을 찾아 다음 글 방향을 제안한다
argument-hint: [CSV 경로, 기본 data/performance.csv]
---

입력: $ARGUMENTS

`docs/performance-analysis.md` 절차를 따른다.

1. CSV 경로를 정한다. 비어 있으면 `data/performance.csv`를 쓴다.
   - 파일이 없으면 만들지 말고, 크리에이터 어드바이저 조회수 순위 1~20위의 제목과 조회수를 `제목,조회수` 형식으로 붙여넣어 달라고 요청한다.
   - 사용자가 채팅에 붙여넣은 표나 목록은 그 형식으로 정리해 CSV로 저장한다. 값은 바꾸지 않는다.
   - 네이버에 접속해 데이터를 자동으로 가져오지 않는다.
2. `node scripts/analyze_performance.js <CSV>`를 실행한다.
3. `data/analysis-latest.md`를 읽고 아래를 짧게 보고한다.
   - 상위 그룹의 교집합: 제목 유형, 도입 후킹, 자주 나온 단어 (각각 근거 숫자와 함께)
   - "(추정)" 표시가 붙은 제목 유형은 추정이라고 밝힌다
   - 다음 글 제안 2~3개: 제목 유형 + 메인 키워드 후보 + 도입 후킹. 제목 문장은 예시 1개만 쓰고, 상위 글 제목을 그대로 베끼지 않는다.
   - 글이 10개 미만이면 "참고용"이라고 먼저 말한다.
4. 상관관계일 뿐 원인이 아니라는 점을 한 줄로 덧붙인다.
5. 규칙 파일(`docs/writing-rules.md`)은 고치지 않는다. 바꿀 만한 점이 보이면 제안만 하고 사용자 승인을 받는다.
