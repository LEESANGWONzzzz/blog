UNBOXED 스마트스토어 자동 등록 - 사용설명서 (윈도우)

[처음 한 번만]
1. 파이썬 설치
   https://www.python.org/downloads/ 에서 내려받아 설치합니다.
   설치 첫 화면 아래의 "Add python.exe to PATH"를 꼭 체크하세요.
2. 1_install.bat 더블클릭 (필요한 부품을 설치합니다)
3. config.ini 를 메모장으로 열어 입력합니다.
   - client_id, client_secret : 커머스API센터 > 애플리케이션에서 받은 값
   - as_phone : A/S·문의 전화번호
   이 파일에는 키가 들어가니 다른 사람에게 보내거나 채팅에 붙여 넣지 마세요.
4. 커머스API센터에서 이 컴퓨터의 IP를 등록합니다.
   2_run.bat → 6번(내 IP 확인)으로 IP를 확인한 뒤,
   커머스API센터 > 애플리케이션 > 수정 > API호출 IP 에 넣으세요.
5. 2_run.bat → 1번(연결 테스트). "연결 성공"이 나오면 준비 끝입니다.
6. 2_run.bat → 3번(주소록)으로 출고지·반품지 번호를 확인해 config.ini 에 넣습니다.

[상품 등록할 때마다]
1. 상품 사진을 "images" 폴더에 넣습니다. (JPG·PNG, 한 상품 최대 10장)
2. products.xlsx 에 상품을 한 줄씩 적습니다. 2번째 줄은 설명이니 지우지 마세요.
   - 판매가를 비우면 매입가와 목표순수익으로 자동 계산합니다.
   - 카테고리ID는 2_run.bat → 2번(카테고리 찾기)으로 찾습니다.
   - 사이즈옵션은 "270:1, 275:2" 처럼 사이즈:수량을 씁니다.
3. 2_run.bat → 4번(미리보기). "결과" 폴더에 요청 내용이 저장됩니다. 오류가 없는지 확인합니다.
4. 2_run.bat → 5번(상품 등록하기) → y 입력.
5. 처음에는 "전시중지"로 등록됩니다. 판매자센터에서 상품을 확인하고 전시로 바꾸세요.
   익숙해지면 products.xlsx 의 전시상태 칸에 ON 을 쓰면 바로 판매중으로 올라갑니다.

[오류가 나면]
- 화면에 나온 오류 메시지를 복사해 Claude나 GPT에 보여주면 고칠 곳을 알려줍니다.
  (config.ini 내용, 특히 client_secret 은 절대 보여주지 마세요.)
- IP_NOT_ALLOWED : 4번(IP 등록)을 다시 확인
- 401 : client_id / client_secret 확인
- 403 : 애플리케이션에 상품·판매자정보 권한 그룹이 있는지 확인
- 원산지·고시정보 오류 : config.ini 의 origin_area_code, [notice] 값을 조정
- 결과 폴더의 .csv 파일에 상품별 성공/실패가 기록됩니다.

[다른 컴퓨터(사무실 PC 등)에서도 쓰기]
1. 이 폴더 전체를 새 컴퓨터로 옮깁니다. config.ini 는 키가 들어 있으니 USB로 옮기거나,
   새 컴퓨터에서 키를 다시 입력하세요. 메신저·메일·채팅으로 보내지 마세요.
2. 새 컴퓨터에서 파이썬 설치 → 1_install.bat 실행.
3. 2_run.bat → 7번(이 컴퓨터 환경 점검). 모두 OK 인지 확인합니다.
4. 7번에 나온 인터넷 IP를 커머스API센터 > 애플리케이션 > 수정 > API호출 IP 에 "추가"로 등록합니다.
   (집 PC IP는 지우지 말고 같이 두세요.)
5. 7번을 다시 실행해 "토큰 발급 : OK" 가 나오면 이 컴퓨터에서도 등록할 수 있습니다.
